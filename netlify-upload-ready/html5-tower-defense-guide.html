Basics

How to play

  1. Place towers near the enemy path.
  2. Start the wave and let towers attack automatically.
  3. Use earned money to build more towers or upgrade existing ones.
  4. Do not block the path completely; the game prevents unfair placement.
  5. Offline download: unzip the folder and open src/td.html.

Defense

Strategy

  • Build near corners so towers hit enemies for longer.
  • Mix cheap early towers with stronger upgrades later.
  • Upgrade towers that already cover busy parts of the map.
  • Save some money before harder waves so you can react.
