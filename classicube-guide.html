ClassiCube

Build worlds in a classic block sandbox.

ClassiCube is focused on creative building, multiplayer servers, and the Minecraft Classic style. It is not modern Minecraft survival.

Movement

Controls

Basic controls

  • WASD: move
  • Mouse: look around
  • Space: jump
  • Left click: remove blocks
  • Right click: place blocks
  • Esc: pause menu and options

Find all controls

Open the pause menu, then go to Options and Controls to see or change the full key list.

Creative

Building tips

  1. Start singleplayer. Use the official play page, choose singleplayer, and load into a world.
  2. Practice placing blocks. Build a small wall, house, or tower first.
  3. Use different blocks. Swap block types to add floors, windows, roofs, paths, and color.
  4. Try multiplayer later. Multiplayer may require a ClassiCube account and some servers need the downloadable client.
  5. Remember the scope. ClassiCube is a classic creative block game, not a modern survival clone.
